# Cursor Boilerplate

Этот репозиторий хранит стартовый boilerplate для проектов, которые ведутся через Cursor с агентным workflow.

## Зачем нужен этот git-репозиторий

- Фиксирует полную историю изменений в правилах, командах и skill-матрице.
- Дает безопасные точки отката, если эксперимент с настройками оказался неудачным.
- Упрощает совместную работу: изменения можно обсуждать через ветки, PR и code review.
- Позволяет стандартизировать запуск проекта через единый набор команд и правил.

## Что находится в репозитории

- `.cursor/rules` — правила поведения агента и рабочие guardrails.
- `.cursor/commands` — проектные команды (`/start-project`, `/review-staged`, `/setup-graphify` и др.).
- `.cursor/skills` — матрица навыков и рекомендации по их применению.
- `docs/superpowers` — шаблоны спецификаций и итерационных планов.
- `.agents/skills` — установленные проектные skills для Cursor.

## Зачем это нужно команде

- Быстрый онбординг: новый участник получает готовую рабочую среду.
- Предсказуемый процесс: plan -> implement -> verify -> review.
- Меньше ручной рутины и ошибок за счет команд и проверок перед коммитом.
- Единый подход к документированию и качеству изменений.

## Базовый сценарий

1. Запустить `/start-project` для первичной настройки контекста и приоритетов.
2. Работать через профильные команды (`/plan-feature`, `/debug-issue`, `/review-staged`).
3. Перед коммитом запускать `/update-docs`, чтобы документация оставалась актуальной.
4. Поддерживать изменения в git через небольшие и понятные коммиты.
