---
description: Run systematic bug investigation and propose validated fixes
---

Debug using a structured flow:
1. Capture exact symptom and reproduction.
2. Identify likely root causes.
3. Validate hypotheses with evidence from code/runtime.
4. Propose minimal safe fix options.
5. Define regression checks and verification commands.

Output:
- `Observed Behavior`
- `Reproduction Steps`
- `Root Cause Hypotheses`
- `Validated Cause`
- `Fix Options`
- `Verification`
